# 常见问题

**凭什么相信它的判定？**
它不靠模型自报身份（自报很容易造假），而是让同一组 24 个短问题各问 24 次，看回答的分布和官方参考指纹是否来自同一个模型，用的是置换检验加 Cauchy 合成。我们在官方 gpt-6-luna 上做了 20 轮独立自测，全部判一致；把 gpt-5.6-luna、gpt-5-nano、gpt-5.4-nano 冒充成 gpt-6-luna，20 次全部被抓到，p 值在 1e-15 量级。方法和原始数据都在 [METHOD.zh-CN.md](METHOD.zh-CN.md)，可以自己复现。

**误报了怎么办？**
先确认三件事：参考指纹是不是同一个模型、同一种 reasoning effort；官方最近有没有更新这个模型（更新后官方端点也会被判不一致）；样本是否够（`--samples 48` 更稳）。仍然误报，请带上 JSON 报告（默认已脱敏）开 issue，我们会优先修。「存疑」（退出码 2）本来就是「证据不够」，不要当成指控。

**为什么不做中转站红黑榜？**
一次测试只代表那一刻、那个模型、那条线路；中转可能部分时间给真模型，也可能对不同用户不同。点名排行榜既不严谨，也容易被拿去打架。relaycheck 只给你一份证据，分享与否你决定，分享卡默认隐藏主机名。

**我的 key 安全吗？**
key 只从环境变量读，只发给你指定的那个地址，不经过任何第三方服务器；报告和日志里的 key、URL 凭证、cookie 都会脱敏。代码零运行时依赖，可以自己审。

**测一次要花多少钱？**
默认一次大约 600 个很短的请求加几个上下文请求。在 gpt-6-luna 这种便宜模型上不到 1 美分；贵模型按比例增加。`--deep`（10 万 token 上下文）会明显更贵，按需开。

**哪些作弊它抓不到？**
大部分时间给真模型、偶尔掺假的中转（80% 真模型时，24 样本只有 7.8% 概率判失败）；能认出固定探针、只把探针转给真模型的中转；同一模型的极近似变体。这些都写在 [METHOD.zh-CN.md](METHOD.zh-CN.md) 的局限里。

**支持哪些模型和协议？**
协议支持 Anthropic Messages、OpenAI Chat Completions、OpenAI Responses。身份检验需要该模型的参考指纹，目前内置 gpt-6-luna；其他模型可以用官方 key 自己生成（`relaycheck fingerprint`），欢迎 PR 贡献到 `refs/`。
